# SOUND / FIELD

Browser-based sound utilities built with TypeScript and the Web Audio API.
Audio files are analyzed locally in your browser and are never uploaded.

## Tools

- **ANALYZE / FIELD** — Real-time spectrum analyzer for local audio files.
- **NOISE / FIELD** — Noise generator with editable frequency curves.
- **MODULATE / FIELD** — Four-operator FM synthesizer with configurable routing.

## Development

```sh
npm ci
npm run dev
```

Run the checks with `npm run check:types`, `npm run lint`, `npm run format:check`,
and `npm test`.
